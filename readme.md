# UJIKOM OOP PHP - Sistem Login

Project ini merupakan aplikasi login sederhana yang dibuat menggunakan PHP dengan konsep Object-Oriented Programming (OOP) serta menerapkan konsep Enkapsulasi.

## 📌 Deskripsi

Aplikasi ini memiliki halaman login yang digunakan untuk memasukkan username dan password.

Data dari form dikirim menggunakan metode POST ke `proses.php`, kemudian divalidasi menggunakan class `Pengguna`.

## 🛠️ Teknologi

- PHP
- HTML
- CSS
- OOP (Object-Oriented Programming)
